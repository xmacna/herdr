# Instruções do projeto Argos

Leia o perfil comum em `{{ARGOS_PROFILE_PATH}}` antes de escolher tom, idioma, nível de detalhe ou frequência de atualização. Preserve a resposta literal do usuário.

Estas são instruções de projeto, não um system prompt do provedor. Ações externas, destrutivas, compras, envios, pareamentos e interrupções continuam exigindo autorização própria.

Use o terminal Herdr e comandos documentados quando uma ação precisar ser executada. Declare capacidades desconhecidas de cada CLI; não suponha que todos carreguem os mesmos arquivos, skills ou recursos de resume.
